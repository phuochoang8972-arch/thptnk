Hướng dẫn lấy link chuẩn để gửi Zalo không bị lỗi 404

⚠️ Vì sao gửi link trực tiếp từ khung xem trước bị lỗi 404?
Link khung xem trước hiện tại là link nội bộ tạm thời, chỉ mình bạn mở được. Khi gửi qua Zalo/Messenger người khác bấm vào sẽ báo 404.
✅ Cách lấy link chuẩn gửi cho 500 bạn (30 giây):
Cách 1 (Khuyên dùng - Vào chung 1 sân trường): Bấm nút Tải xuống (Download) file index.html ở góc trên bên phải khung code → kéo thả vào tiiny.host hoặc app.netlify.com/drop để lấy link web thật gửi Zalo!
Cách 2 (Chia sẻ nhanh): Bấm biểu tượng Chia sẻ (Share) của khung Canvas ở góc trên cùng bên phải màn hình.
